Theme Transformation Plan (Universe/Space)

1. Core CMS/Admin Functionality
- Keep all content management features: add/edit/remove skills, projects, etc.
- Maintain authentication and admin dashboard logic.
- Ensure editing from web remains intuitive and accessible.

2. Visual Theme & UI/UX
- Replace library/book metaphor with universe/space (planets, galaxies, constellations).
- Update navigation to a star map or orbiting menu.
- Use deep space colors, neon accents, and cosmic backgrounds.
- Futuristic fonts and glowing effects for headings.

3. Section Layouts
- About: Astronaut profile or mission log.
- Projects: Each project as a planet/star system, modal/flyout for details.
- Skills: Skill constellations or planets with orbiting satellites.
- Experience/Journey: Timeline as rocket trajectory or constellation path.
- Contact: Signal form with animated radio waves or satellite imagery.

4. Interactive Elements
- Hover effects: planets spin, stars twinkle, orbits animate.
- Parallax scrolling for depth.
- Modal popups for project/skill details with cosmic transitions.

5. Background & Effects
- Animated starfield, nebula clouds, galaxies.
- Shooting stars, comet trails, cosmic dust.
- Optional subtle space ambience sound.

6. Accessibility & Performance
- Offer reduced motion toggle.
- Maintain good contrast and readability.
- Ensure responsiveness and fast load times.

7. Inspiration & Tools
- Reference space-themed portfolios on Awwwards, CodePen, Dribbble.
- Use Three.js, Lottie, or CSS/JS for effects.

Summary: Preserve CMS/admin features and editing logic, but transform visuals and UI/UX to a universe/space theme for a unique, immersive portfolio.
